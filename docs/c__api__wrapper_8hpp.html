Detailed Description

Collection of C API wrappers.

This file is located in include/esp_private because it is not intended for users, but rather for esp_modem C extension developers.

The C extension API must provide a 'factory function' that returns initialized pointer to esp_modem_dce_wrap. Helper functions provided below, can be used for conversion between C++ enum classes and standard C enums.
