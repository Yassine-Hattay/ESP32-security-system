13 * @info
14 * PBKDF2_hmac- password based key derivation function based on HMAC.
15 * The API acts as a password based key derivation function by using the hardware HMAC peripheral present on the SoC. The hmac key shall be used from the efuse key block provided as the hmac_key_id. The API makes use of the hardware HMAC peripheral and hardware SHA peripheral present on the SoC. The SHA operation is limited to SHA256.
16 * @input
17 * hmac_key_id The efuse_key_id in which the HMAC key has already been burned.
18 * This key should be read and write protected for its protection. That way it can only be accessed by the hardware HMAC peripheral.
19 * salt The buffer containing the salt value
20 * salt_len The length of the salt in bytes
21 * key_length The expected length of the derived key.
22 * iteration_count The count for which the internal cryptographic operation shall be repeated.
23 * output The pointer to the buffer in which the derived key shall be stored. It must of a writable buffer of size key_length bytes
24 *
25 */
26int esp_pbkdf2_hmac_sha256(hmac_key_id_t hmac_key_id, const unsigned char *salt, size_t salt_len,
