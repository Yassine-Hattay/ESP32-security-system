\begin{DoxyParagraph}{Timer functionality.}

\end{DoxyParagraph}
The idea is\+: platform has some timer which can be stopped or run. When run, it increments (or decrements -\/ depends on platform) some counter until counter overflow (underflow), then issues interrupt -\/ wakeups main loop if it sleeping. Time stored in ticks; time resolution is platform dependent, its usual value is 15.\+36 usec -\/ 1 beacon interval. \begin{DoxyNote}{Note}
Time type has limited capacity (usually 16 bits) and can overflow. Macros which works with time handles overflow. It is supposed that time values will not differ to more then 1/2 of the maximum time value.
\end{DoxyNote}
All that timer macros will not be used directly by the application code -\/ it is scheduler internals. The only API for timer is ZB\+\_\+\+SCHEDULE\+\_\+\+ALARM() call. Timer type.
