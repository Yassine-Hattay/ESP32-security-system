\doxysubsection{Detailed Description}
The Zigbee ZDO bind command struct. 

\begin{DoxyNote}{Note}
Current implementation of the API ONLY supports 64 bit extended address\textquotesingle{}s address mode. Other address mode will support later.

Be aware of the one req\+\_\+dst\+\_\+addr is address that command send to, while dst\+\_\+address is the destination of the binding entry.
