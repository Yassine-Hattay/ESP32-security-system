\hypertarget{README.md_autotoc_md1242}{}\doxysubsection{\texorpdfstring{Overview}{Overview}}\label{README.md_autotoc_md1242}
The aim of this test is to run {\ttfamily iperf} application to measure network throughput of the esp\+\_\+modem library.\hypertarget{README.md_autotoc_md1243}{}\doxysubsubsection{\texorpdfstring{Configure PPP server}{Configure PPP server}}\label{README.md_autotoc_md1243}
This test uses a network DCE device, which only needs a PPP server. To run the PPP server, use this command\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{sudo\ pppd\ /dev/ttyUSB1\ 115200\ 192.168.11.1:192.168.11.2\ ms-\/dns\ 8.8.8.8\ modem\ local\ noauth\ debug\ nocrtscts\ nodetach\ +ipv6}

\end{DoxyCode}
\hypertarget{README.md_autotoc_md1244}{}\doxysubsubsection{\texorpdfstring{Running using pytest}{Running using pytest}}\label{README.md_autotoc_md1244}
For checking the performance, you only need to execute the pytest, which will measure the network throughput automatically and report the resultant values. For running the pytest, you need to\+:
\begin{DoxyItemize}
\item install IDF pytest packages by running\+: {\ttfamily ./install.sh -\/-\/enable-\/pytest}
\item add IDF internal packages to python path\+: {\ttfamily export PYTHONPATH=\$\{DIF\+\_\+\+PATH\}/tools/ci/python\+\_\+packages/}
\item run the pytest as {\bfseries{superuser}}
\end{DoxyItemize}

It\textquotesingle{}s useful to note that when running the test multiple times, you can use {\ttfamily pytest -\/-\/skip-\/autoflash y} so the pytest wouldn\textquotesingle{}t have to always reprogram the DUT.\hypertarget{README.md_autotoc_md1245}{}\doxysubsubsection{\texorpdfstring{Performance summary}{Performance summary}}\label{README.md_autotoc_md1245}

\hypertarget{README.md_autotoc_md1246}{}\doxysubsubsection{\texorpdfstring{Running the iperf manually}{Running the iperf manually}}\label{README.md_autotoc_md1246}
Execute {\ttfamily idf.\+py flash monitor} in one terminal and after connecting to the PPP server (after getting an IP address), you can use standard {\ttfamily iperf} commands. In another terminal, you need to execute the iperf counterpart. For example running for checking \doxylink{class_u_d_p}{UDP} performance, and running server on ESP32, please run\+:
\begin{DoxyItemize}
\item iperf -\/u -\/s -\/i 3 (in ESP32 terminal)
\item iperf -\/u -\/c SERVER\+\_\+\+IP -\/t 60 -\/i 3 (on the host side)
\end{DoxyItemize}
