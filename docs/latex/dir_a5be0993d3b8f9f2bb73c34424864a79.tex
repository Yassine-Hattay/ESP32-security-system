Sodium is a new, easy-\/to-\/use software library for encryption, decryption, signatures, password hashing and more.

It is a portable, cross-\/compilable, installable, packageable fork of \href{http://nacl.cr.yp.to/}{\texttt{ Na\+Cl}}, with a compatible API, and an extended API to improve usability even further.

Its goal is to provide all of the core operations needed to build higher-\/level cryptographic tools.

Sodium supports a variety of compilers and operating systems, including Windows (with MingW or Visual Studio, x86 and x64), i\+OS, Android, as well as Javascript and Webassembly.\hypertarget{README.md_autotoc_md1326}{}\doxysubsubsection{\texorpdfstring{Documentation}{Documentation}}\label{README.md_autotoc_md1326}
