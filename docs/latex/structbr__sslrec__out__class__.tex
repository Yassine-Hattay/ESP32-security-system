Perform record encryption. 

This function encrypts the record. The plaintext address and length are provided. Returned value is the start of the encrypted record (or sequence of records, if a split was performed), {\itshape including} the 5-\/byte header, and {\ttfamily \texorpdfstring{$\ast$}{*}len} is adjusted to the total size of the record(s), there again including the header(s).

Compute maximum plaintext sizes and offsets. 

When this function is called, the {\ttfamily \texorpdfstring{$\ast$}{*}start} and {\ttfamily \texorpdfstring{$\ast$}{*}end} values contain offsets designating the free area in the outgoing buffer for plaintext data; that free area is preceded by a 5-\/byte space which will receive the record header.

The {\ttfamily \doxylink{structbr__sslrec__out__class___ad51570d6d9cc017374dc750b7641976e}{max\+\_\+plaintext()}} function is responsible for adjusting both {\ttfamily \texorpdfstring{$\ast$}{*}start} and {\ttfamily \texorpdfstring{$\ast$}{*}end} to make room for any record-\/specific header, MAC, padding, and possible split.
