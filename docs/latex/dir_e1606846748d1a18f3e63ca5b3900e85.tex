\doxysubsection{Detailed Description}
EEPROM is deprecated. For new applications on ESP32, use \doxylink{class_preferences}{Preferences}. EEPROM is provided for backwards compatibility with existing Arduino applications. EEPROM is implemented using a single blob within NVS, so it is a container within a container. As such, it is not going to be a high performance storage method. \doxylink{class_preferences}{Preferences} will directly use nvs, and store each entry as a single object therein.
