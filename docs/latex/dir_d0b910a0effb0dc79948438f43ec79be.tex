\doxysubsection{Detailed Description}
\href{https://components.espressif.com/components/espressif/esp_modem}{\texttt{ }}

The {\ttfamily esp-\/modem} component is a managed component for {\ttfamily esp-\/idf} that is used for communication with GSM/\+LTE modems that support AT commands and PPP protocol as a network interface.\hypertarget{README.md_autotoc_md1234}{}\doxysubsection{\texorpdfstring{Examples}{Examples}}\label{README.md_autotoc_md1234}
Get started with one of the examples\+:
\begin{DoxyItemize}
\item {\ttfamily examples/pppos\+\_\+client} -- simple client implemented in C
\item {\ttfamily examples/modem\+\_\+console} -- C++ example implementing simple terminal console with DCE commands
\item {\ttfamily examples/ap\+\_\+to\+\_\+pppos} -- this example focuses on the network connectivity of the esp-\/modem and provides a Wi\+Fi AP that forwards packets (and uses NAT) to and from the PPPoS connection.
\item {\ttfamily examples/simple\+\_\+cmux\+\_\+client} -- this example sets up the CMUX mode to talk to the modem using AT commands with simultaneously maintaining active network connection.
