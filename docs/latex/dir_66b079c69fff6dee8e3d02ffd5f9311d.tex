\doxysubsection{Detailed Description}
(See the README.\+md file in the upper level \textquotesingle{}examples\textquotesingle{} directory for more information about examples.)\hypertarget{README.md_autotoc_md1228}{}\doxysubsection{\texorpdfstring{Overview}{Overview}}\label{README.md_autotoc_md1228}
This example shows how to act as a MQTT client after the PPPoS channel created by using \href{https://docs.espressif.com/projects/esp-idf/en/latest/api-reference/protocols/mqtt.html}{\texttt{ ESP-\/\+MQTT}} APIs.\hypertarget{README.md_autotoc_md1229}{}\doxysubsection{\texorpdfstring{How to use this example}{How to use this example}}\label{README.md_autotoc_md1229}
See the README.\+md file in the upper level {\ttfamily pppos} directory for more information about the PPPoS examples.\hypertarget{README.md_autotoc_md1230}{}\doxysubsubsection{\texorpdfstring{USB DTE support}{USB DTE support}}\label{README.md_autotoc_md1230}
For USB enabled targets (ESP32-\/\+S2, ESP32-\/\+S3, or ESP32-\/\+P4), it is possible to connect to the modem device via USB.
\begin{DoxyEnumerate}
\item In menuconfig, navigate to {\ttfamily Example Configuration-\/\texorpdfstring{$>$}{>}Type of serial connection to the modem} and choose {\ttfamily USB}.
\item Connect the modem USB signals to your ESP chip (pin 19 (DATA-\/) and 20 (DATA+) for ESP32-\/\+S2/\+S3).
\end{DoxyEnumerate}

USB example uses Quactel BG96 modem device. BG96 needs a positive pulse on its PWK pin to boot-\/up.

This example supports USB modem hot-\/plugging and reconnection.
