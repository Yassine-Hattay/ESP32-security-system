\item A USB cable for power supply and programming

In this example, the internal temperature sensor task is reading the chip temperature. Set the Button Switch GPIO by changing the {\ttfamily GPIO\+\_\+\+INPUT\+\_\+\+IO\+\_\+\+TOGGLE\+\_\+\+SWITCH} definition. By default, it\textquotesingle{}s the {\ttfamily GPIO\+\_\+\+NUM\+\_\+9} (BOOT button on ESP32-\/\+C6 and ESP32-\/\+H2).\hypertarget{README.md_autotoc_md785}{}\doxysubsubsubsubsection{\texorpdfstring{Using Arduino IDE}{Using Arduino IDE}}\label{README.md_autotoc_md785}
