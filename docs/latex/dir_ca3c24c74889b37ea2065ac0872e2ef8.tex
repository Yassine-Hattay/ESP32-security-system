\doxysubsection{Detailed Description}
This example demonstrates how to build a custom device to be used with ESP Rain\+Maker.\hypertarget{README.md_autotoc_md484}{}\doxysubsection{\texorpdfstring{What to expect in this example?}{What to expect in this example?}}\label{README.md_autotoc_md484}

\begin{DoxyItemize}
\item This example sketch uses the on board Boot button and GPIO16 to demonstrate an ESP Rain\+Maker AC dimmer device.
\item After compiling and flashing the example, add your device using the \href{https://rainmaker.espressif.com/docs/quick-links.html\#phone-apps}{\texttt{ ESP Rain\+Maker phone apps}} by scanning the QR code.
\item Toggling the state from the phone app will toggle the dimmer state (GPIO16).
\item Pressing the Boot button will toggle the dimmer state (GPIO16) and the same will reflect on the phone app.
\item You can also change the Level from the phone app and see it reflect on the device as a print message.
