\doxysubsection{Detailed Description}
This is an example of implementing minimal network module functionality. 

This is a null-\/module, doesn\textquotesingle{}t define any AT commands, just passes everything to pppd.

This does only include those AT commands, that are needed for setting the network up and also initialization part (set pin, ...)
