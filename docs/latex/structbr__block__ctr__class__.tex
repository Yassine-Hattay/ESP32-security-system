Run the CTR encryption or decryption. 

The {\ttfamily iv} parameter points to the IV for this run; its length is exactly 4 bytes less than the block size (e.\+g. 12 bytes for AES/\+CTR). The IV is combined with a 32-\/bit block counter to produce the block value which is processed with the block cipher.

The data to encrypt or decrypt is updated "{}in place"{}. Its length ({\ttfamily len} bytes) is not required to be a multiple of the block size; if the final block is partial, then the corresponding key stream bits are dropped.

The resulting counter value is returned.
