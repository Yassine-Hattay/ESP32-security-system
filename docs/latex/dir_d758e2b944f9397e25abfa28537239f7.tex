\doxysubsection{Detailed Description}
While building any examples for ESP Rain\+Maker, take care of the following\+:


\begin{DoxyEnumerate}
\item Change the partition scheme that fits your flash size in Arduino IDE to {\ttfamily Rain\+Maker 4MB}, {\ttfamily Rain\+Maker 4MB no OTA} or {\ttfamily Rain\+Maker 8MB} (Tools -\/\texorpdfstring{$>$}{>} Partition Scheme -\/\texorpdfstring{$>$}{>} Rain\+Maker).
\item Once ESP Rain\+Maker gets started, compulsorily call {\ttfamily Wi\+Fi.\+begin\+Provision()} which is responsible for user-\/node mapping.
\item Use the appropriate provisioning scheme as per the board.
\begin{DoxyItemize}
\item ESP32 Board\+: BLE Provisioning
\item ESP32-\/\+C3 Board\+: BLE Provisioning
\item ESP32-\/\+S3 Board\+: BLE Provisioning
\item ESP32-\/\+S2 Board\+: Soft\+AP Provisioning
\item ESP32-\/\+C6 Board\+: BLE Provisioning
\item ESP32-\/\+H2 Board\+: BLE Provisioning
\end{DoxyItemize}
\item Set debug level to Info (Tools -\/\texorpdfstring{$>$}{>} Core Debug Level -\/\texorpdfstring{$>$}{>} Info). This is the recommended debug level but not mandatory to run Rain\+Maker. 
\end{DoxyEnumerate}
