\doxysubsection{Detailed Description}
RSA private key. 

The structure references the private factors, reduced private exponents, and CRT coefficient. It also contains the bit length of the modulus. The big integers use unsigned big-\/endian representation; extra leading bytes of value 0 are allowed. However, the modulus bit length ({\ttfamily n\+\_\+bitlen}) MUST be exact.
