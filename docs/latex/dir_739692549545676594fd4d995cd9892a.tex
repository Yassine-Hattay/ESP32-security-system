\doxysubsection{Detailed Description}
(See the README.\+md file in the upper level \textquotesingle{}examples\textquotesingle{} directory for more information about examples.)

This example demonstrates how to use 2D convolution dspi\+\_\+conv\+\_\+f32 from esp-\/dsp library. Example does the following steps\+:


\begin{DoxyEnumerate}
\item Initialize the input arrays
\item Calculate 2D convolution of two images
\end{DoxyEnumerate}

The example reproduce the Matlab code\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{A\ =\ ones(8);}
\DoxyCodeLine{B\ =\ ones(4);}
\DoxyCodeLine{Csame\ =\ conv2(A,B,\ "{}same"{})}

\end{DoxyCode}
