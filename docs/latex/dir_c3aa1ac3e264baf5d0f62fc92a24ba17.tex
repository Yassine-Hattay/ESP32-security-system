This is the simplest buildable example made to be used as a template for new projects running Arduino-\/esp32 as an ESP-\/\+IDF component. See \href{https://components.espressif.com/components/espressif/arduino-esp32}{\texttt{ Arduino-\/esp32}} in ESP Registry.\hypertarget{README.md_autotoc_md9}{}\doxysubsubsection{\texorpdfstring{How to use example}{How to use example}}\label{README.md_autotoc_md9}
To create a ESP-\/\+IDF project from this example with the latest release of Arduino-\/esp32, you can simply run command\+: {\ttfamily idf.\+py create-\/project-\/from-\/example "{}espressif/arduino-\/esp32\+:hello\+\_\+world"{}}. ESP-\/\+IDF will download all dependencies needed from the component registry and setup the project for you.

If you want to use cloned Arduino-\/esp32 repository, you can build this example directly. Go to the example folder {\ttfamily arduino-\/esp32/idf\+\_\+component\+\_\+examples/hello\+\_\+world}. First you need to comment line 6 {\ttfamily pre\+\_\+release\+: true} in examples {\ttfamily /main/idf\+\_\+component.yml}. Then just run command\+: {\ttfamily idf.\+py build}.\hypertarget{README.md_autotoc_md10}{}\doxysubsubsection{\texorpdfstring{Example folder contents}{Example folder contents}}\label{README.md_autotoc_md10}
