\doxysubsection{Detailed Description}
(See the README.\+md file in the upper level \textquotesingle{}examples\textquotesingle{} directory for more information about examples.)\hypertarget{README.md_autotoc_md1232}{}\doxysubsection{\texorpdfstring{Overview}{Overview}}\label{README.md_autotoc_md1232}
This example demonstrates the use of the \href{https://components.espressif.com/component/espressif/esp_modem}{\texttt{ esp-\/modem component}} to connect to a network and send some AT commands. It uses modem CMUX mode so that commands and network could be used at the same time.

The example uses the following configuration options to demonstrate basic esp-\/modem capabilities\+:
\begin{DoxyItemize}
\item {\ttfamily EXAMPLE\+\_\+\+NEED\+\_\+\+SIM\+\_\+\+PIN}\+: To unlock the SIM card with a PIN code if needed
\item {\ttfamily EXAMPLE\+\_\+\+PERFORM\+\_\+\+OTA}\+: To start simple OTA at the end of the example to exercise basic CMUX/modem networking. Please note that the option {\ttfamily CONFIG\+\_\+\+UART\+\_\+\+ISR\+\_\+\+IN\+\_\+\+IRAM} is not enabled automatically, so that buffer overflows are expected and CMUX/\+PPP and networking should recover.
\item {\ttfamily EXAMPLE\+\_\+\+USE\+\_\+\+VFS\+\_\+\+TERM}\+: To demonstrate using an abstract file descriptor to talk to the device (instead of the UART driver directly). This option could be used when implementing a custom VFS driver. 
\end{DoxyItemize}
