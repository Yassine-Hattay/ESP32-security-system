\doxysubsection{Detailed Description}
Group of functions used to encode data to CBOR. 

\doxylink{struct_cbor_encoder}{Cbor\+Encoder} is used to encode data into a CBOR stream. The outermost \doxylink{struct_cbor_encoder}{Cbor\+Encoder} is initialized by calling \doxylink{group___cbor_encoding_ga257051966d907f88af804f30f2e9d8e2}{cbor\+\_\+encoder\+\_\+init()}, with the buffer where the CBOR stream will be stored. The outermost \doxylink{struct_cbor_encoder}{Cbor\+Encoder} is usually used to encode exactly one item, most often an array or map. It is possible to encode more than one item, but care must then be taken on the decoder side to ensure the state is reset after each item was decoded.

Nested \doxylink{struct_cbor_encoder}{Cbor\+Encoder} objects are created using \doxylink{group___cbor_encoding_ga9fe6843f957d3586641363216fbc7359}{cbor\+\_\+encoder\+\_\+create\+\_\+array()} and \doxylink{group___cbor_encoding_gaa92a4da104e30885dc567075e7d1230a}{cbor\+\_\+encoder\+\_\+create\+\_\+map()}, later closed with \doxylink{group___cbor_encoding_ga70cff492f984c4a64a72e4d8a717027b}{cbor\+\_\+encoder\+\_\+close\+\_\+container()} or \doxylink{group___cbor_encoding_gaa597ba3b072473a41448e131ca20a66b}{cbor\+\_\+encoder\+\_\+close\+\_\+container\+\_\+checked()}. The pairs of creation and closing must be exactly matched and their parameters are always the same.

\doxylink{struct_cbor_encoder}{Cbor\+Encoder} writes directly to the user-\/supplied buffer, without extra buffering. \doxylink{struct_cbor_encoder}{Cbor\+Encoder} does not allocate memory and \doxylink{struct_cbor_encoder}{Cbor\+Encoder} objects are usually created on the stack of the encoding functions.

\doxysubsubsubsection*{Error checking and buffer size}

All functions operating on \doxylink{struct_cbor_encoder}{Cbor\+Encoder} return a condition of type Cbor\+Error. If the encoding was successful, they return Cbor\+No\+Error. Some functions do extra checking on the input provided and may return some other error conditions (for example, \doxylink{group___cbor_encoding_ga923a63a01dae47a3dd46f74a3f744008}{cbor\+\_\+encode\+\_\+simple\+\_\+value()} checks that the type is of the correct type).

In addition, all functions check whether the buffer has enough bytes to encode the item being appended. If that is not possible, they return Cbor\+Error\+Out\+Of\+Memory.

It is possible to continue with the encoding of data past the first function that returns Cbor\+Error\+Out\+Of\+Memory. \doxylink{struct_cbor_encoder}{Cbor\+Encoder} functions will not overrun the buffer, but will instead count how many more bytes are needed to complete the encoding. At the end, you can obtain that count by calling \doxylink{group___cbor_encoding_gab5e3be4701e47f9756a86643aa2937dc}{cbor\+\_\+encoder\+\_\+get\+\_\+extra\+\_\+bytes\+\_\+needed()}.
