Please take a look at how to build, flash, and run \href{https://github.com/espressif/esp-idf/tree/master/tools/unit-test-app\#unit-test-app}{\texttt{ esp-\/idf unit tests}}.

Follow the steps mentioned below to unit test the diagnostics data store


\begin{DoxyItemize}

\begin{DoxyCode}{0}
\DoxyCodeLine{cd\ \$IDF\_PATH/tools/unit-\/test-\/app}

\end{DoxyCode}
