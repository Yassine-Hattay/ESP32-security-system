\doxysubsection{Detailed Description}
\href{https://components.espressif.com/components/espressif/network_provisioning}{\texttt{ }}

The network provisioning component provides APIs that control the network provisioning service for receiving and configuring network credentials via secure \href{https://docs.espressif.com/projects/esp-idf/en/stable/esp32/api-reference/provisioning/protocomm.html}{\texttt{ Protocol Communication}} sessions.

It currently supports both Wi-\/\+Fi and Thread network provisioning\+:
\begin{DoxyItemize}
\item Provision Wi-\/\+Fi credentials over Soft\+AP or Bluetooth LE
\item Provision Thread credentials over Bluetooth LE 
\end{DoxyItemize}
