\doxysubsection{Detailed Description}
Collection of C API wrappers. 

This file is located in include/esp\+\_\+private because it is not intended for users, but rather for esp\+\_\+modem C extension developers.

The C extension API must provide a \textquotesingle{}factory function\textquotesingle{} that returns initialized pointer to \doxylink{structesp__modem__dce__wrap}{esp\+\_\+modem\+\_\+dce\+\_\+wrap}. Helper functions provided below, can be used for conversion between C++ enum classes and standard C enums.
