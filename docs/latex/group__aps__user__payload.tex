Set callback to be called when ZDO command packet is sent. 

That callback is to be used when application wants to know the fact that ZDO command send is completed.

Callback provided to ZBOSS ZDO request function (second parameter of zb\+\_\+zdo\+\_\+node\+\_\+desc\+\_\+req and similar function) not always can be used for that purpose. ZBOSS calls ZDO callback immediately when a) unicast transmit of APS message failed (no ACK) and b) this is ZDO message that does not suppose to have an answer, like broadcast NWK Update req. In other cases if callback is set using zb\+\_\+af\+\_\+set\+\_\+zdo\+\_\+data\+\_\+conf\+\_\+cb, it is called when outgoing ZDO command is sent; callback passed to zb\+\_\+zdo\+\_\+node\+\_\+desc\+\_\+req and friends is called when ZBOSS got response/responses to ZDO command, or ZDO command is timed out.
