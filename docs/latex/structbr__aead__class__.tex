Compute and check authentication tag. 

This function is an alternative to {\ttfamily \doxylink{structbr__aead__class___ad82862e02f7ba926fc9e5c41396ad8df}{get\+\_\+tag()}}, and is normally used on the receiving end (i.\+e. when decrypting messages). The tag value is recomputed and compared with the provided tag value. If they match, 1 is returned; on mismatch, 0 is returned. A returned value of 0 means that the data or the tag was altered in transit, normally leading to wholesale rejection of the complete message.

\doxylink{struct_tag}{Tag} length depends on the AEAD algorithm.

Compute authentication tag. 

Compute the AEAD authentication tag. The tag length depends on the AEAD algorithm; it is written in the provided {\ttfamily tag} buffer. This call terminates the AEAD run\+: no data may be processed with that AEAD context afterwards, until {\ttfamily \doxylink{structbr__aead__class___a55ce10a7cd2c2e889034193918e33d06}{reset()}} is called to initiate a new AEAD run.

The tag value must normally be sent along with the encrypted data. When decrypting, the tag value must be recomputed and compared with the received tag\+: if the two tag values differ, then either the tag or the encrypted data was altered in transit. As an alternative to this function, the {\ttfamily \doxylink{structbr__aead__class___a4980a5af6176bc6ae2709f6ab5b4501e}{check\+\_\+tag()}} function may be used to compute and check the tag value.

\doxylink{struct_tag}{Tag} length depends on the AEAD algorithm.

Reset an AEAD context. 

This function resets an already initialised AEAD context for a new computation run. Implementations and keys are conserved. This function can be called at any time; it cancels any ongoing AEAD computation that uses the provided context structure.

The provided IV is a {\itshape nonce}. Each AEAD algorithm has its own requirements on IV size and contents; for most of them, it is crucial to security that each nonce value is used only once for a given secret key.

Data encryption or decryption can be done after {\ttfamily \doxylink{structbr__aead__class___a44c7640148ff5e3008307252130b4957}{flip()}} has been called on the context. If {\ttfamily encrypt} is non-\/zero, then the provided data shall be plaintext, and it is encrypted in place. Otherwise, the data shall be ciphertext, and it is decrypted in place.

Data may be provided in several chunks of arbitrary length.
