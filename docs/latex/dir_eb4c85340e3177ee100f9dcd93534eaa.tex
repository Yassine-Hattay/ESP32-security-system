\doxysubsection{Detailed Description}
This example demonstrates how to build a custom device to be used with ESP Rain\+Maker using Mode, Range and Toggle Parameters.\hypertarget{README.md_autotoc_md488}{}\doxysubsection{\texorpdfstring{What to expect in this example?}{What to expect in this example?}}\label{README.md_autotoc_md488}

\begin{DoxyItemize}
\item This example sketch uses the on board Boot button and GPIOs 16, 17, 18, 19, 21, 22 to demonstrate an ESP Rain\+Maker Air\+Cooler device.
\item After compiling and flashing the example, add your device using the \href{https://rainmaker.espressif.com/docs/quick-links.html\#phone-apps}{\texttt{ ESP Rain\+Maker phone apps}} by scanning the QR code.
\item Toggling the power state from the phone app will toggle GPIO 16.
\item Pressing the Boot button will toggle the power state (GPIO 16) and the same will reflect on the phone app.
\item Toggling the swing state from the phone app will toggle GPIO 17.
\item Changing the mode from the phone app will toggle the GPIOs 18 (auto), 19 (cool) and 21 (heat)
\item Changing the Speed slider from the phone app will dimming GPIO 22
\item You can also change the Level from the phone app and see it reflect on the device as a print message.
