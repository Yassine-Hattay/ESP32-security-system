\doxysubsection{Detailed Description}
\hypertarget{README.md_autotoc_md1054}{}\doxysubsection{\texorpdfstring{Overview}{Overview}}\label{README.md_autotoc_md1054}
An Espressif ESP-\/\+Modbus Library (esp-\/modbus) is a library to support Modbus communication in the networks based on RS485, Wi\+Fi, Ethernet interfaces. The Modbus is a data communications protocol originally published by Modicon (now Schneider Electric) in 1979 for use with its programmable logic controllers (PLCs).


\begin{DoxyItemize}
\item \href{https://www.github.com/espressif/esp-modbus}{\texttt{ ESP-\/\+Modbus component on Git\+Hub}}
\end{DoxyItemize}

This library is to be used with Espressif’s IoT Development Framework, \href{https://github.com/espressif/esp-idf}{\texttt{ ESP\+\_\+\+IDF}}. The packages from this repository are uploaded to Espressif’s component repository.


\begin{DoxyItemize}
\item \href{https://components.espressif.com/component/espressif/esp-modbus}{\texttt{ esp-\/modbus component in component repository}}
\end{DoxyItemize}

You can add the component to your project via {\ttfamily idf.\+py add-\/dependency}. More information about idf-\/component-\/manager can be found in \href{https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-guides/tools/idf-component-manager.html}{\texttt{ Espressif API guide}} or \href{https://pypi.org/project/idf-component-manager}{\texttt{ Py\+Pi registry}}.

The ESP-\/\+Modbus library can be used with ESP-\/\+IDF v4.\+1 and later. ESP-\/\+IDF v4.\+x releases include an earlier version of ESP-\/\+Modbus library inside freemodbus component. To use ESP-\/\+Modbus with these releases, users need to exclude the built-\/in freemodbus component from the build process, and update application components to depend on esp-\/modbus component instead. To exclude freemodbus component from compilation, add the following line to the project CMake\+Lists.\+txt file\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{set(EXCLUDE\_COMPONENTS\ freemodbus)}

\end{DoxyCode}


ESP-\/\+IDF v5.\+x and later releases do not include freemodbus component, so no extra steps are necessary when adding esp-\/modbus component.\hypertarget{README.md_autotoc_md1055}{}\doxysubsection{\texorpdfstring{Documentation}{Documentation}}\label{README.md_autotoc_md1055}
