\doxysubsection{Detailed Description}
This example is designed to demonstrate the absolute basics of using \href{https://www.tensorflow.org/lite/microcontrollers}{\texttt{ Tensor\+Flow Lite for Microcontrollers}}. It includes the full end-\/to-\/end workflow of training a model, converting it for use with Tensor\+Flow Lite for Microcontrollers for running inference on a microcontroller.

The model is trained to replicate a {\ttfamily sine} function and generates a pattern of data to either blink LEDs or control an animation, depending on the capabilities of the device.\hypertarget{README.md_autotoc_md578}{}\doxysubsection{\texorpdfstring{Deploy to ESP32}{Deploy to ESP32}}\label{README.md_autotoc_md578}
