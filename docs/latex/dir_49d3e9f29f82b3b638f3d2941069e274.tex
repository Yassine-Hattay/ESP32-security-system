\doxysubsection{Detailed Description}
This is an experimental port of the esp\+\_\+modem to linux. It mocks some IDF functionality with {\ttfamily port/linux} layers (used for modem host test suite) and implements {\ttfamily esp\+\_\+netif}, which supports {\ttfamily tun} interface and uses lw\+IP {\ttfamily ppp} implementation to parse or wrap IP packets to be send/receive over PPPoS, i.\+e. over the modem serial line.\hypertarget{README.md_autotoc_md1212}{}\doxysubsection{\texorpdfstring{Configuration}{Configuration}}\label{README.md_autotoc_md1212}
