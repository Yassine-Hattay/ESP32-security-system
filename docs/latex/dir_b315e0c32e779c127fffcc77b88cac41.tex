\doxysubsection{Detailed Description}
\hypertarget{README.md_autotoc_md1061}{}\doxysubsection{\texorpdfstring{Overview}{Overview}}\label{README.md_autotoc_md1061}
Example demonstrates how to flash ESP32/\+ESP32-\/\+S2/\+ESP8266 from another (host) MCU using esp\+\_\+serial\+\_\+flash component API. In this case, ESP32 is also used as host MCU. Binaries to be flashed from host MCU to another Espressif SoC can be found in {\ttfamily binaries} folder and are converted into C-\/array during build process.

Following steps are performed in order to re-\/program target\textquotesingle{}s memory\+:


\begin{DoxyEnumerate}
\item Filesystem is initialized and mounted.
\item UART1 through which new binary will be transfered is initialized.
\item Host puts slave device into boot mode tries to connect by calling {\ttfamily esp\+\_\+loader\+\_\+connect()}.
\item Binary file is opened and its size is acquired, as it has to be known before flashing.
\item Then {\ttfamily esp\+\_\+loader\+\_\+flash\+\_\+start()} is called to enter flashing mode and erase amount of memory to be flashed.
\item {\ttfamily esp\+\_\+loader\+\_\+flash\+\_\+write()} function is called repeatedly until the whole binary image is transfered.
\end{DoxyEnumerate}

Note\+: In addition, to steps mentioned above, {\ttfamily esp\+\_\+loader\+\_\+change\+\_\+transmission\+\_\+rate} is called after connection is established in order to increase flashing speed. This does not apply for ESP8266, as its bootloader does not support this command. However, ESP8266 is capable of detecting baud rate during connection phase, and can be changed before calling {\ttfamily esp\+\_\+loader\+\_\+connect}, if necessary.\hypertarget{README.md_autotoc_md1062}{}\doxysubsection{\texorpdfstring{SPI pin initialization}{SPI pin initialization}}\label{README.md_autotoc_md1062}
In majority of cases {\ttfamily ESP\+\_\+\+LOADER\+\_\+\+CONNECT\+\_\+\+DEFAULT} helper macro is used in order to initialize {\ttfamily loader\+\_\+connect\+\_\+args\+\_\+t} data structure passed to {\ttfamily esp\+\_\+loader\+\_\+connect}. Helper macro sets {\ttfamily spi\+\_\+pin\+\_\+config} field of the data structure to zero, thus, default SPI pins are used to connect to FLASH memory. In special cases, such as custom design in which FLASH is connected to different pins, {\ttfamily spi\+\_\+pin\+\_\+config} field has to be set accordingly. For more detailed information refer to \href{https://docs.espressif.com/projects/esptool/en/latest/esp32s3/advanced-topics/serial-protocol.html}{\texttt{ serial protocol}}.\hypertarget{README.md_autotoc_md1063}{}\doxysubsection{\texorpdfstring{Hardware Required}{Hardware Required}}\label{README.md_autotoc_md1063}

\begin{DoxyItemize}
\item Two development boards with ESP32 SoC (e.\+g., ESP32-\/\+Dev\+KitC, ESP-\/\+WROVER-\/\+KIT, etc.).
\item One or two USB cables for power supply and programming.
\end{DoxyItemize}\hypertarget{README.md_autotoc_md1064}{}\doxysubsection{\texorpdfstring{Hardware connection}{Hardware connection}}\label{README.md_autotoc_md1064}
