\doxysubsection{Detailed Description}
SHAKE context. 

The HKDF context is initialized with a "{}security level"{}. The internal notion is called "{}capacity"{}; the capacity is twice the security level (for instance, SHAKE128 has capacity 256).

The caller is responsible for allocating the context where appropriate. Context initialisation and usage incurs no dynamic allocation, so there is no release function.
