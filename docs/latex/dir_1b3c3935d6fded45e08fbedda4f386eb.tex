\doxysubsection{Detailed Description}
\hypertarget{README.md_autotoc_md1069}{}\doxysubsection{\texorpdfstring{Overview}{Overview}}\label{README.md_autotoc_md1069}
Example demonstrates how to flash ESP32 from Raspberry Pi 4 (Model B) using esp\+\_\+serial\+\_\+flash component API. AT command firmware to be flashed from Raspberry Pi to ESP32 can be found in {\ttfamily binaries}. USART0 is dedicated for communication with ESP32.

Following steps are performed in order to re-\/program target\textquotesingle{}s memory\+:


\begin{DoxyEnumerate}
\item Peripherals are initialized.
\item Host puts slave device into boot mode tries to connect by calling {\ttfamily esp\+\_\+loader\+\_\+connect()}.
\item Then {\ttfamily esp\+\_\+loader\+\_\+flash\+\_\+start()} is called to enter flashing mode and erase amount of memory to be flashed.
\item {\ttfamily esp\+\_\+loader\+\_\+flash\+\_\+write()} function is called repeatedly until the whole binary image is transfered.
\item At the end, {\ttfamily loader\+\_\+port\+\_\+reset\+\_\+target()} is called to restart ESP32 and execute updated firmware.
\end{DoxyEnumerate}

Note\+: In addition, to steps mentioned above, {\ttfamily esp\+\_\+loader\+\_\+change\+\_\+transmission\+\_\+rate} is called after connection is established in order to increase flashing speed. Bootloader is also capable of detecting baud rate during connection phase, and can be changed before calling {\ttfamily esp\+\_\+loader\+\_\+connect}. However, it is recommended to start at lower speed and then use dedicated command to increase baud rate. This does not apply for ESP8266, as its bootloader does not support this command, therefore, baud rate can only be changed before connection phase in this case.\hypertarget{README.md_autotoc_md1070}{}\doxysubsection{\texorpdfstring{Hardware Required}{Hardware Required}}\label{README.md_autotoc_md1070}

\begin{DoxyItemize}
\item Raspberry Pi 4 Model B.
\item A development board with ESP32 SoC (e.\+g. ESP-\/\+WROVER-\/\+KIT, ESP32-\/\+Dev\+KitC, etc.).
\item USB cable in case ESP32 board is powered from USB. ESP32 can be powered by Raspberry Pi as well.
\end{DoxyItemize}\hypertarget{README.md_autotoc_md1071}{}\doxysubsection{\texorpdfstring{Hardware connection}{Hardware connection}}\label{README.md_autotoc_md1071}

\hypertarget{README.md_autotoc_md1073}{}\doxysubsubsection{\texorpdfstring{GPIO library}{GPIO library}}\label{README.md_autotoc_md1073}
Raspberry Pi makes use of \href{http://abyz.me.uk/rpi/pigpio/}{\texttt{ pigpio}} library in order to simplify controlling GPIO pins. Some distributions of \textquotesingle{}Raspberry Pi OS\textquotesingle{} may come with {\ttfamily pigpio} already installed. Presence of the library in the system can checked by running command\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{pigpiod\ -\/v}

\end{DoxyCode}


If not present, run following commands to install the library. 
\begin{DoxyCode}{0}
\DoxyCodeLine{sudo\ apt-\/get\ update}
\DoxyCodeLine{sudo\ apt-\/get\ install\ pigpio}

\end{DoxyCode}

\begin{DoxyCode}{0}
\DoxyCodeLine{sudo\ raspi-\/config}

\end{DoxyCode}
