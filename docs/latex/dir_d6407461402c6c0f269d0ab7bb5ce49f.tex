\hypertarget{README.md_autotoc_md444}{}\doxysubsubsection{\texorpdfstring{Lifecycle of the test (Hard reset resets the cycle)}{Lifecycle of the test (Hard reset resets the cycle)}}\label{README.md_autotoc_md444}

\begin{DoxyItemize}
\item Device boots up and logs errors/warnings/events in random order every 10 seconds
\item Every error/warning/event log with "{}diag\+\_\+smoke"{} tag is associated with an incremental counter
\item There\textquotesingle{}s a 30/500 probability that device will crash, this is done for verification of crash
\item Device will crash only five times and hard reset will reset the counter to 1
\item On sixth boot onwards device will not crash and logs errors/warnings/events and adds heap metrics
\end{DoxyItemize}\hypertarget{README.md_autotoc_md445}{}\doxysubsubsection{\texorpdfstring{Facilitate the Auth Key}{Facilitate the Auth Key}}\label{README.md_autotoc_md445}
