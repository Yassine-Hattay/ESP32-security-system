Decrypt the incoming record. 

This function may assume that the record length is valid (it has been previously tested with {\ttfamily \doxylink{structbr__sslrec__in__class___afdec2ccf5032e90a6abab8f115487ac0}{check\+\_\+length()}}). Decryption is done in place; {\ttfamily \texorpdfstring{$\ast$}{*}len} is updated with the cleartext length, and the address of the first plaintext byte is returned. If the record is correct but empty, then {\ttfamily \texorpdfstring{$\ast$}{*}len} is set to 0 and a non-\/{\ttfamily NULL} pointer is returned.

On decryption/\+MAC error, {\ttfamily NULL} is returned.
