\hypertarget{README.md_autotoc_md1469}{}\doxysubsection{\texorpdfstring{Description}{Description}}\label{README.md_autotoc_md1469}
{\ttfamily esp\+\_\+prov} -\/ A python-\/based utility for testing the provisioning examples over a host machine.

Usage of {\ttfamily esp-\/prov} assumes that the provisioning app has specific protocomm endpoints active. These endpoints are active in the provisioning examples and accept specific protobuf data structure\+:

 \hypertarget{README.md_autotoc_md1471}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{README.md_autotoc_md1471}

\begin{DoxyItemize}
\item {\ttfamily -\/-\/help} \doxylink{class_print}{Print} the list of options along with brief descriptions
\item {\ttfamily -\/-\/verbose}, {\ttfamily -\/v} Sets the verbosity level of output log
\item {\ttfamily -\/-\/transport \texorpdfstring{$<$}{<}mode\texorpdfstring{$>$}{>}}
\begin{DoxyItemize}
\item Three options are available\+:
\begin{DoxyItemize}
\item {\ttfamily softap} -\/ for Soft\+AP + HTTPD based provisioning
\begin{DoxyItemize}
\item Requires the device to be running in Wi-\/\+Fi Soft\+AP mode and hosting an HTTP server supporting specific endpoint URIs
\item The client needs to be connected to the device soft\+AP network before running the {\ttfamily esp\+\_\+prov} tool.
\end{DoxyItemize}
\item {\ttfamily ble} -\/ for Bluetooth LE based provisioning
\begin{DoxyItemize}
\item Supports Linux, Windows and mac\+OS; redirected to console if dependencies are not met
\item Assumes that the provisioning endpoints are active on the device with specific Bluetooth LE service UUIDs
\end{DoxyItemize}
\item {\ttfamily console} -\/ for debugging via console-\/based provisioning
\begin{DoxyItemize}
\item The client-\/\texorpdfstring{$>$}{>}device commands are printed to STDOUT and device-\/\texorpdfstring{$>$}{>}client messages are accepted via STDIN.
\item This is to be used when the device is accepting provisioning commands on UART console.
\end{DoxyItemize}
\item {\ttfamily httpd} -\/ the script works the same as for {\ttfamily softap}. This could be used on any other network interface than Wi\+Fi soft AP, e.\+g. Ethernet or USB.
\end{DoxyItemize}
\end{DoxyItemize}
\item {\ttfamily -\/-\/service\+\_\+name \texorpdfstring{$<$}{<}name\texorpdfstring{$>$}{>}} (Optional)
\begin{DoxyItemize}
\item When transport mode is {\ttfamily ble}, this specifies the Bluetooth LE device name to which connection is to be established for provisioned. If not provided, Bluetooth LE scanning is initiated and a list of nearby devices, as seen by the host, is displayed, of which the target device can be chosen.
\item When transport mode is {\ttfamily softap} or {\ttfamily httpd}, this specifies the HTTP server hostname / IP which is running the provisioning service, on the Soft\+AP network (or any other interface for {\ttfamily httpd} mode) of the device which is to be provisioned. This defaults to {\ttfamily 192.\+168.\+4.\+1\+:80} if not specified
\end{DoxyItemize}
\item {\ttfamily -\/-\/ssid \texorpdfstring{$<$}{<}AP SSID\texorpdfstring{$>$}{>}} (Optional)
\begin{DoxyItemize}
\item For specifying the SSID of the Wi-\/\+Fi AP to which the device is to connect after provisioning.
\item If not provided, scanning is initiated and scan results, as seen by the device, are displayed, of which an SSID can be picked and the corresponding password specified.
\end{DoxyItemize}
\item {\ttfamily -\/-\/passphrase \texorpdfstring{$<$}{<}AP Password\texorpdfstring{$>$}{>}} (Optional)
\begin{DoxyItemize}
\item For specifying the password of the Wi-\/\+Fi AP to which the device is to connect after provisioning.
\item Only used when corresponding SSID is provided using the {\ttfamily -\/-\/ssid} option
\end{DoxyItemize}
\item {\ttfamily -\/-\/dataset\+\_\+tlvs \texorpdfstring{$<$}{<}Thread Dataset Tlvs\texorpdfstring{$>$}{>}} (Optional)
\begin{DoxyItemize}
\item For specifying the Dataset Tlvs of the Thread network to which the device is to connect after provisioning.
\end{DoxyItemize}
\item {\ttfamily -\/-\/sec\+\_\+ver \texorpdfstring{$<$}{<}Security version number\texorpdfstring{$>$}{>}}
\begin{DoxyItemize}
\item For specifying the version of protocomm endpoint security to use. Following 3 versions are supported\+:
\begin{DoxyItemize}
\item {\ttfamily 0} for {\ttfamily protocomm\+\_\+security0} -\/ No security
\item {\ttfamily 1} for {\ttfamily protocomm\+\_\+security1} -\/ X25519 key exchange + Authentication using Proof of Possession (PoP) + AES-\/\+CTR encryption
\item {\ttfamily 2} for {\ttfamily protocomm\+\_\+security2} -\/ Secure Remote Password protocol (SRP6a) + AES-\/\+GCM encryption
\end{DoxyItemize}
\end{DoxyItemize}
\item {\ttfamily -\/-\/pop \texorpdfstring{$<$}{<}Proof of possession string\texorpdfstring{$>$}{>}} (Optional)
\begin{DoxyItemize}
\item For specifying optional Proof of Possession string to use for protocomm endpoint security version 1
\item Ignored when other security versions are used
\end{DoxyItemize}
\item {\ttfamily -\/-\/sec2\+\_\+username \texorpdfstring{$<$}{<}SRP6a Username\texorpdfstring{$>$}{>}} (Optional)
\begin{DoxyItemize}
\item For specifying optional username to use for protocomm endpoint security version 2
\item Ignored when other security versions are used
\end{DoxyItemize}
\item {\ttfamily -\/-\/sec2\+\_\+pwd \texorpdfstring{$<$}{<}SRP6a Password\texorpdfstring{$>$}{>}} (Optional)
\begin{DoxyItemize}
\item For specifying optional password to use for protocomm endpoint security version 2
\item Ignored when other security versions are used
\end{DoxyItemize}
\item {\ttfamily -\/-\/sec2\+\_\+gen\+\_\+cred} (Optional)
\begin{DoxyItemize}
\item For generating the {\ttfamily SRP6a} credentials (salt and verifier) from the provided username and password for protocomm endpoint security version 2
\item Ignored when other security versions are used
\end{DoxyItemize}
\item {\ttfamily -\/-\/sec2\+\_\+salt\+\_\+len \texorpdfstring{$<$}{<}SRP6a Salt Length\texorpdfstring{$>$}{>}} (Optional)
\begin{DoxyItemize}
\item For specifying the optional {\ttfamily SRP6a} salt length to be used for generating protocomm endpoint security version 2 credentials
\item Ignored when other security versions are used and the {\ttfamily -\/-\/sec2\+\_\+gen\+\_\+cred} option is not set
\end{DoxyItemize}
\item {\ttfamily -\/-\/reset} (Optional)
\begin{DoxyItemize}
\item Resets internal state machine of the device and clears provisioned credentials; to be used only in case of provisioning failures
\end{DoxyItemize}
\item {\ttfamily -\/-\/reprov} (Optional)
\begin{DoxyItemize}
\item Resets internal state machine of the device and clears provisioned credentials; to be used only in case the device is to be provisioned again for new credentials after a previous successful provisioning
\end{DoxyItemize}
\item {\ttfamily -\/-\/custom\+\_\+data \texorpdfstring{$<$}{<}some string\texorpdfstring{$>$}{>}} (Optional) An information string can be sent to the {\ttfamily custom-\/data} endpoint during provisioning using this argument. (Assumes the provisioning app has an endpoint called {\ttfamily custom-\/data} -\/ see \href{../../examples/wifi_prov/}{\texttt{ wifi\+\_\+prov}} example for implementation details).
