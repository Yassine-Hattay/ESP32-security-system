\doxysubsection{Detailed Description}
This example demonstrates the basic usage of Free\+RTOS Queues which enables tasks to pass data between each other in a secure asynchronous way. Please refer to other examples in this folder to better understand the usage of tasks. It is also advised to read the documentation on Free\+RTOS web pages\+: \href{https://www.freertos.org/a00106.html}{\texttt{ https\+://www.\+freertos.\+org/a00106.\+html}}

This example reads data received on the serial port (sent by the user) pass it via queue to another task which will send it back on Serial Output.\hypertarget{README.md_autotoc_md413}{}\doxysubsubsection{\texorpdfstring{Theory\+:}{Theory\+:}}\label{README.md_autotoc_md413}
A queue is a simple-\/to-\/use data structure (in the most basic way) controlled by {\ttfamily x\+Queue\+Send} and {\ttfamily x\+Queue\+Receive} functions. Usually, one task writes into the queue and the other task reads from it. Usage of queues enables the reading task to yield the CPU until there are data in the queue and therefore not waste precious computation time.\hypertarget{README.md_autotoc_md414}{}\doxysubsection{\texorpdfstring{Supported Targets}{Supported Targets}}\label{README.md_autotoc_md414}
This example supports all ESP32 So\+Cs.\hypertarget{README.md_autotoc_md415}{}\doxysubsubsection{\texorpdfstring{How to Use Example}{How to Use Example}}\label{README.md_autotoc_md415}
Flash and write anything to serial input.
