\doxysubsection{Detailed Description}
\hypertarget{README.md_autotoc_md1104}{}\doxysubsection{\texorpdfstring{Introduction}{Introduction}}\label{README.md_autotoc_md1104}
This component contains a binary library supporting the esp-\/zigbee-\/lib. It provides most of the APIs that users could use in the Zigbee product project development. ~\newline
 In this component it provides\+: ~\newline

\begin{DoxyItemize}
\item Varieties of ZDO, ZCL command ~\newline

\item Standard Home Automation off-\/the-\/shelf devices ~\newline

\item Zigbee stack related functions to support ZC, ZR and ZED ~\newline

\item Varieties of device callback to support device handling ZCL command ~\newline

\item Customized function to create attribute, cluster and endpoint ~\newline

\item Zigbee security to support install code related function ~\newline

\item More to come ... ... ~\newline

\end{DoxyItemize}

For the list of current supported ZCL clusters, attributes, commands, Zigbee Home Automation devices, see details \href{https://docs.espressif.com/projects/esp-zigbee-sdk/en/latest/esp32/developing.html\#zigbee-product}{\texttt{ docs}}.
