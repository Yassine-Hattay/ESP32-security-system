\doxysubsection{Detailed Description}
This example demonstrates how to use the Fine Timing Measurement (FTM) to calculate the distance from the Access Point and the device. This is calculated by the Wi-\/\+Fi Round Trip Time (Wi-\/\+Fi RTT) introduced on the \href{https://en.wikipedia.org/wiki/IEEE_802.11mc}{\texttt{ IEEE Std 802.\+11-\/2016}} standard.

This example will simulate the Router with FTM capability.

This example was based on the \href{https://github.com/espressif/esp-idf/tree/master/examples/wifi/ftm}{\texttt{ ESP-\/\+IDF FTM}}. See the README file for more details about on how to use this feature.

Some usages for this feature includes\+:


\begin{DoxyItemize}
\item Indoor positioning systems.
\item Navigation.
\item Device Location.
\item Smart Devices.
\item Alarms.
