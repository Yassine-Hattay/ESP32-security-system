\hypertarget{README.md_autotoc_md387}{}\doxysubsection{\texorpdfstring{Search Criteria}{Search Criteria}}\label{README.md_autotoc_md387}
Search crieria is used for searching the mailbox for messages that match the given searching criteria. ~\newline


Searching criteria consist of one or more search keys. When multiple keys are specified, the result is the intersection (AND function) of all the messages that match those keys. ~\newline


Example\+:

{\bfseries{{\ttfamily DELETED FROM "{}\+SMITH"{} SINCE 1-\/Feb-\/1994}}} refers to all deleted messages from Smith that were placed in the mailbox since February 1, 1994. ~\newline


A search key can also be a parenthesized list of one or more search keys (e.\+g., for use with the OR and NOT keys).

{\bfseries{{\ttfamily SINCE 10-\/Feb-\/2019}}} will search all messages that received since 10 Feb 2019

{\bfseries{{\ttfamily UID SEARCH ALL}}} will seach all message which will return the message UID that can be use later for fetch one or more messages.

The following keywords can be used for the search criteria.

{\bfseries{ALL}} -\/ All messages in the mailbox; the default initial key for ANDing.

{\bfseries{ANSWERED}} -\/ Messages with the \textbackslash{}\+Answered flag set.

{\bfseries{BCC}} -\/ Messages that contain the specified string in the envelope structure\textquotesingle{}s BCC field.

{\bfseries{BEFORE}} -\/ Messages whose internal date (disregarding time and timezone) is earlier than the specified date.

{\bfseries{BODY}} -\/ Messages that contain the specified string in the body of the message.

{\bfseries{CC}} -\/ Messages that contain the specified string in the envelope structure\textquotesingle{}s CC field.

{\bfseries{DELETED}} -\/ Messages with the \textbackslash{}\+Deleted flag set.

{\bfseries{DRAFT}} -\/ Messages with the \textbackslash{}\+Draft flag set.

{\bfseries{FLAGGED}} -\/ Messages with the \textbackslash{}\+Flagged flag set.

{\bfseries{FROM}} -\/ Messages that contain the specified string in the envelope structure\textquotesingle{}s FROM field.

{\bfseries{HEADER}} -\/ Messages that have a header with the specified field-\/name (as defined in \mbox{[}RFC-\/2822\mbox{]})

and that contains the specified string in the text of the header (what comes after the colon).

If the string to search is zero-\/length, this matches all messages that have a header line with

the specified field-\/name regardless of the contents.

{\bfseries{KEYWORD}} -\/ Messages with the specified keyword flag set.

{\bfseries{LARGER}} -\/ Messages with an (RFC-\/2822) size larger than the specified number of octets.

{\bfseries{NEW}} -\/ Messages that have the \textbackslash{}\+Recent flag set but not the \textbackslash{}\+Seen flag.

This is functionally equivalent to {\bfseries{"{}(\+RECENT UNSEEN)"{}}}.

{\bfseries{NOT}} -\/ Messages that do not match the specified search key.

{\bfseries{OLD}} -\/ Messages that do not have the \textbackslash{}\+Recent flag set. This is functionally equivalent to

{\bfseries{"{}\+NOT RECENT"{}}} (as opposed to {\bfseries{"{}\+NOT NEW"{}}}).

{\bfseries{ON}} -\/ Messages whose internal date (disregarding time and timezone) is within the specified date.

{\bfseries{OR}} -\/ Messages that match either search key.

{\bfseries{RECENT}} -\/ Messages that have the \textbackslash{}\+Recent flag set.

{\bfseries{SEEN}} -\/ Messages that have the \textbackslash{}\+Seen flag set.

{\bfseries{SENTBEFORE}} -\/ Messages whose (RFC-\/2822) Date\+: header (disregarding time and timezone) is earlier than the specified date.

{\bfseries{SENTON}} -\/ Messages whose (RFC-\/2822) Date\+: header (disregarding time and timezone) is within the specified date.

{\bfseries{SENTSINCE}} -\/ Messages whose (RFC-\/2822) Date\+: header (disregarding time and timezone) is within or later than the specified date.

{\bfseries{SINCE}} -\/ Messages whose internal date (disregarding time and timezone) is within or later than the specified date.

{\bfseries{SMALLER}} -\/ Messages with an (RFC-\/2822) size smaller than the specified number of octets.

{\bfseries{SUBJECT}} -\/ Messages that contain the specified string in the envelope structure\textquotesingle{}s SUBJECT field.

{\bfseries{TEXT}} -\/ Messages that contain the specified string in the header or body of the message.

{\bfseries{TO}} -\/ Messages that contain the specified string in the envelope structure\textquotesingle{}s TO field.

{\bfseries{UID}} -\/ Messages with unique identifiers corresponding to the specified unique identifier set. ~\newline


Sequence set ranges are permitted.

{\bfseries{UNANSWERED}} -\/ Messages that do not have the \textbackslash{}\+Answered flag set.

{\bfseries{UNDELETED}} -\/ Messages that do not have the \textbackslash{}\+Deleted flag set.

{\bfseries{UNDRAFT}} -\/ Messages that do not have the \textbackslash{}\+Draft flag set.

{\bfseries{UNFLAGGED}} -\/ Messages that do not have the \textbackslash{}\+Flagged flag set.

{\bfseries{UNKEYWORD}} -\/ Messages that do not have the specified keyword flag set.
