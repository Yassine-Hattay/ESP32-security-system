\doxysubsection{Detailed Description}
Context structure for a SSL client. 

The first field (called {\ttfamily eng}) is the SSL engine; all functions that work on a {\ttfamily \doxylink{structbr__ssl__engine__context}{br\+\_\+ssl\+\_\+engine\+\_\+context}} structure shall take as parameter a pointer to that field. The other structure fields are opaque and must not be accessed directly.
