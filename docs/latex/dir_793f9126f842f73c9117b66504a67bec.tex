\doxysubsection{Detailed Description}
This example shows how to configure Zigbee Coordinator and use it as a Home Automation (HA) color dimmer light switch.\hypertarget{README.md_autotoc_md732}{}\doxysubsection{\texorpdfstring{Supported Targets}{Supported Targets}}\label{README.md_autotoc_md732}

\begin{DoxyItemize}
\item One development board (ESP32-\/\+H2 or ESP32-\/\+C6) acting as Zigbee end device (loaded with Zigbee\+\_\+\+Color\+\_\+\+Dimmable\+\_\+\+Light example).
\item A USB cable for power supply and programming.
\item Choose another board (ESP32-\/\+H2 or ESP32-\/\+C6) as Zigbee coordinator and upload the Zigbee\+\_\+\+Color\+\_\+\+Dimmable\+\_\+\+Light example.

If the End device flashed with the example {\ttfamily Zigbee\+\_\+\+Color\+\_\+\+Dimmable\+\_\+\+Light} is not connecting to the coordinator, erase the flash of the End device before flashing the example to the board. It is recommended to do this if you re-\/flash the coordinator. You can do the following\+:


\begin{DoxyItemize}
\item In the Arduino IDE go to the Tools menu and set {\ttfamily Erase All Flash Before Sketch Upload} to {\ttfamily Enabled}.
\item Add to the sketch {\ttfamily Zigbee.\+factory\+Reset();} to reset the device and Zigbee stack.
\end{DoxyItemize}

By default, the coordinator network is closed after rebooting or flashing new firmware. To open the network you have 2 options\+:


\begin{DoxyItemize}
\item Open network after reboot by setting {\ttfamily Zigbee.\+set\+Reboot\+Open\+Network(time);} before calling {\ttfamily Zigbee.\+begin();}.
\item In application you can anytime call {\ttfamily Zigbee.\+open\+Network(time);} to open the network for devices to join.
\end{DoxyItemize}

\item {\bfseries{COM port not detected\+:}} Check the USB cable and the USB to Serial driver installation.
\end{DoxyItemize}
