\doxysubsection{Detailed Description}
This example demonstrates how to use the Wi-\/\+Fi library to scan available Wi-\/\+Fi networks and print the results.

This example shows the basic functionality of the dual antenna capability.\hypertarget{README.md_autotoc_md682}{}\doxysubsection{\texorpdfstring{Supported Targets}{Supported Targets}}\label{README.md_autotoc_md682}
