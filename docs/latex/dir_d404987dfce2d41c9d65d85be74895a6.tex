\doxysubsection{Detailed Description}
\hypertarget{README.md_autotoc_md1077}{}\doxysubsection{\texorpdfstring{Overview}{Overview}}\label{README.md_autotoc_md1077}
Example demonstrates how to flash ESP32 from another STM32 (host MCU) using esp\+\_\+serial\+\_\+flash component API. STM32\+F4-\/\+Discovery board is used in this example, as STM32\+F407\+VG has FLASH memory large enough to fit the whole hello-\/world example of ESP32. Binaries to be flashed from host MCU to ESP32 can be found in {\ttfamily binaries} directory and converted into C-\/arrays during build process. USART1 is dedicated for communication with ESP32, whereas, USART2 can be used for debug purposes by attaching UART-\/to-\/\+USB bridge.

Following steps are performed in order to re-\/program target\textquotesingle{}s memory\+:


\begin{DoxyEnumerate}
\item Peripherals are initialized.
\item Host puts slave device into boot mode tries to connect by calling {\ttfamily esp\+\_\+loader\+\_\+connect()}.
\item Then {\ttfamily esp\+\_\+loader\+\_\+flash\+\_\+start()} is called to enter flashing mode and erase amount of memory to be flashed.
\item {\ttfamily esp\+\_\+loader\+\_\+flash\+\_\+write()} function is called repeatedly until the whole binary image is transfered.
\end{DoxyEnumerate}

Note\+: In addition, to steps mentioned above, {\ttfamily esp\+\_\+loader\+\_\+change\+\_\+transmission\+\_\+rate} is called after connection is established in order to increase flashing speed. Bootloader is also capable of detecting baud rate during connection phase, and can be changed before calling {\ttfamily esp\+\_\+loader\+\_\+connect}. However, it is recommended to start at lower speed and then use dedicated command to increase baud rate. This does not apply for ESP8266, as its bootloader does not support this command, therefore, baud rate can only be changed before connection phase in this case.\hypertarget{README.md_autotoc_md1078}{}\doxysubsection{\texorpdfstring{Hardware Required}{Hardware Required}}\label{README.md_autotoc_md1078}

\begin{DoxyItemize}
\item STM32\+F4-\/\+Discovery board.
\item A development board with ESP32 SoC (e.\+g. ESP-\/\+WROVER-\/\+KIT, ESP32-\/\+Dev\+KitC, etc.).
\item One or two USB cables for power supply and programming.
\end{DoxyItemize}\hypertarget{README.md_autotoc_md1079}{}\doxysubsection{\texorpdfstring{Hardware connection}{Hardware connection}}\label{README.md_autotoc_md1079}
