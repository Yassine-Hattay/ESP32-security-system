\doxysubsection{Detailed Description}
\hypertarget{README.md_autotoc_md1209}{}\doxysubsection{\texorpdfstring{Overview}{Overview}}\label{README.md_autotoc_md1209}
This example focuses on the networking part, enables forwarding packets between network interfaces. It creates a Wi\+Fi soft AP, which uses NAT to forward packets to and from the PPP network interface.\hypertarget{README.md_autotoc_md1210}{}\doxysubsubsection{\texorpdfstring{Specific network DCE}{Specific network DCE}}\label{README.md_autotoc_md1210}
Note, that this example could use of a minimal Network DCE, defined in the {\ttfamily network\+\_\+dce.\+cpp} file. Please set {\ttfamily EXAMPLE\+\_\+\+USE\+\_\+\+MINIMAL\+\_\+\+DCE} to {\ttfamily y} in order to demonstrate this functionality.

By default, this example simply connects to the PPP server using a supported device with C-\/\+API modem interface.

This example however, doesn\textquotesingle{}t rely on sending specific AT commands, just the bare minimum to setup the cellular network. Thus, if the {\ttfamily EXAMPLE\+\_\+\+USE\+\_\+\+MINIMAL\+\_\+\+DCE} option is enabled, we directly inherit from the {\ttfamily Module\+If} and implement only the basic commands. Also, to demonstrate the dce\+\_\+factory functionality, a new {\ttfamily \doxylink{class_net_d_c_e___factory}{Net\+DCE\+\_\+\+Factory}} is implemented for creating the network module and the DCE.
