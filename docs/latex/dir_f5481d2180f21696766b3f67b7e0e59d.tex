\doxysubsection{Detailed Description}
This example demonstrates reading and writing data from and to a web service which can be used for logging data, creating insights and taking actions based on those data.\hypertarget{README.md_autotoc_md641}{}\doxysubsection{\texorpdfstring{Supported Targets}{Supported Targets}}\label{README.md_autotoc_md641}

Please note that this public channel can be accessed by anyone and it is possible that more people will write their values.\hypertarget{README.md_autotoc_md643}{}\doxysubsubsubsection{\texorpdfstring{Configure the Project}{Configure the Project}}\label{README.md_autotoc_md643}
Change {\ttfamily SSID} and {\ttfamily password} to connect to your Wi-\/\+Fi. Default values will allow you to use this example without any changes. If you want to use your own channel and you don\textquotesingle{}t have one already follow these steps\+:


\begin{DoxyItemize}
\item Create an account on \href{https://www.thingspeak.com}{\texttt{ thingspeak.\+com}}.
\item After logging in, click on the "{}\+New Channel"{} button to create a new channel for your data. This is where your data will be stored and displayed.
\item Fill in the Name, Description, and other fields for your channel as desired, then click the "{}\+Save Channel"{} button.
\item Take note of the "{}\+Write API Key"{} located in the "{}\+API keys"{} tab, this is the key you will use to send data to your channel.
\item Replace the channel\+ID from tab "{}\+Channel Settings"{} and private\+Key with "{}\+Read API Keys"{} from "{}\+API Keys"{} tab.
\item Replace the host variable with the thingspeak server hostname "{}api.\+thingspeak.\+com"{}
\item Upload the sketch to your ESP32 board and make sure that the board is connected to the internet. The ESP32 should now send data to your Thingspeak channel at the intervals specified by the loop function.
\item Go to the channel view page on thingspeak and check the "{}\+Field1"{} for the new incoming data.
\item You can use the data visualization and analysis tools provided by Thingspeak to display and process your data in various ways.
\item Please note, that Thingspeak accepts only integer values.
\end{DoxyItemize}\hypertarget{README.md_autotoc_md644}{}\doxysubsubsubsubsection{\texorpdfstring{Config example\+:}{Config example\+:}}\label{README.md_autotoc_md644}

{\itshape {\bfseries{Important\+: Make sure you are using a good quality USB cable and that you have a reliable power source}}}


\begin{DoxyItemize}
\item {\bfseries{Wi-\/\+Fi not connected\+:}} Check the SSID and password and also that the signal has sufficient strength.
\item {\bfseries{400 Bad Request\+:}} Check the write\+Api\+Key.
\item {\bfseries{404 Not Found\+:}} Check the channel ID.
\item {\bfseries{No data on chart / reading NULL\+:}} Data must be sent as an integer, without commas.
\end{DoxyItemize}
