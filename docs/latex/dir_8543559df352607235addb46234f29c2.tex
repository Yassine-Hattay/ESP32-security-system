\doxysubsection{Detailed Description}
This example shows how to configure the Zigbee end device and use it as a Home Automation (HA) on/off light.\hypertarget{README.md_autotoc_md756}{}\doxysubsection{\texorpdfstring{Supported Targets}{Supported Targets}}\label{README.md_autotoc_md756}

\begin{DoxyItemize}
\item One development board (ESP32-\/\+H2 or ESP32-\/\+C6) acting as Zigbee coordinator (loaded with Zigbee\+\_\+\+On\+\_\+\+Off\+\_\+switch example)
\item A USB cable for power supply and programming
\item Choose another board (ESP32-\/\+H2 or ESP32-\/\+C6) as Zigbee end device and upload the Zigbee\+\_\+\+On\+\_\+\+Off\+\_\+\+Light example
\end{DoxyItemize}\hypertarget{README.md_autotoc_md758}{}\doxysubsubsubsection{\texorpdfstring{Configure the Project}{Configure the Project}}\label{README.md_autotoc_md758}
Set the LED GPIO by changing the {\ttfamily LED\+\_\+\+PIN} definition. By default, the LED\+\_\+\+PIN is {\ttfamily RGB\+\_\+\+BUILTIN}. By default, the {\ttfamily rgb\+Led\+Write} function is used to control the LED. You can change it to digital\+Write to control a simple LED.\hypertarget{README.md_autotoc_md759}{}\doxysubsubsubsubsection{\texorpdfstring{Using Arduino IDE}{Using Arduino IDE}}\label{README.md_autotoc_md759}

If the End device flashed with this example is not connecting to the coordinator, erase the flash of the End device before flashing the example to the board. It is recommended to do this if you re-\/flash the coordinator. You can do the following\+:


\begin{DoxyItemize}
\item In the Arduino IDE go to the Tools menu and set {\ttfamily Erase All Flash Before Sketch Upload} to {\ttfamily Enabled}.
\item Add to the sketch {\ttfamily Zigbee.\+factory\+Reset();} to reset the device and Zigbee stack.
\end{DoxyItemize}

By default, the coordinator network is closed after rebooting or flashing new firmware. To open the network you have 2 options\+:


\begin{DoxyItemize}
\item Open network after reboot by setting {\ttfamily Zigbee.\+set\+Reboot\+Open\+Network(time);} before calling {\ttfamily Zigbee.\+begin();}.
\item In application you can anytime call {\ttfamily Zigbee.\+open\+Network(time);} to open the network for devices to join.
\end{DoxyItemize}

{\itshape {\bfseries{Important\+: Make sure you are using a good quality USB cable and that you have a reliable power source}}}


\begin{DoxyItemize}
\item {\bfseries{LED not blinking\+:}} Check the wiring connection and the IO selection.
\item {\bfseries{Programming Fail\+:}} If the programming/flash procedure fails, try reducing the serial connection speed.
\item {\bfseries{COM port not detected\+:}} Check the USB cable and the USB to Serial driver installation.
\end{DoxyItemize}
