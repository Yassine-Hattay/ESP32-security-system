The {\ttfamily Open\+Thread\+CLI} class is an Arduino API for interacting with the Open\+Thread Command Line Interface (CLI). It allows you to manage and configure the Thread stack using a command-\/line interface.

There is one main class called {\ttfamily Open\+Thread\+CLI} and a global object used to operate Open\+Thread CLI, called {\ttfamily OThread\+CLI}.\textbackslash{} Some \doxysectlink{md__c_1_2_users_2hatta_2_desktop_2presonal-projects_2security-camera_2esp-idf-vs-ext_2_e_s_p-32-a8d01a8fe01e76dac7e08b554ef4e243}{helper functions}{0} were made available for working with the Open\+Thread CLI environment.

The available Open\+Thread Commands are documented in the \href{https://openthread.io/reference/cli/commands}{\texttt{ Open\+Thread CLI Reference Page}}

It is important to note that the current implementation can only be used with Espressif SoC that has support to IEEE 802.\+15.\+4, such as {\bfseries{ESP32-\/\+C6}} and {\bfseries{ESP32-\/\+H2}}.
