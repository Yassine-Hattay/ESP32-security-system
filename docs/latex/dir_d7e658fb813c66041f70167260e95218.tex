\doxysubsection{Detailed Description}
This repository contains binary libraries supporting the Zboss Zigbee 3.\+0 stack for ESP32 series chips.

Packages from this repository are uploaded to \href{https://components.espressif.com/}{\texttt{ Espressif\textquotesingle{}s component serivce}}. You can add them to your project via {\ttfamily idf.\+py add-\/dependency}

More information about idf-\/component-\/manager can be found in \href{https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-guides/tools/idf-component-manager.html}{\texttt{ Espressif API guide}} or \href{https://pypi.org/project/idf-component-manager/}{\texttt{ Py\+Pi registry}}.
