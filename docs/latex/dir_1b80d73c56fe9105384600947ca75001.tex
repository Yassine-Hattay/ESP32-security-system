\doxysubsection{Detailed Description}
This example demonstrates the basic usage of Free\+RTOS Tasks for multi threading.

Please refer to other examples in this folder to better utilize their full potential and safeguard potential problems. It is also advised to read the documentation on Free\+RTOS web pages\+: \href{https://www.freertos.org/a00106.html}{\texttt{ https\+://www.\+freertos.\+org/a00106.\+html}}

This example will blink the built-\/in LED and read analog data. Additionally, this example demonstrates the usage of the task handle, simply by deleting the analog read task after 10 seconds from the main loop by calling the function {\ttfamily v\+Task\+Delete}.\hypertarget{README.md_autotoc_md396}{}\doxysubsubsection{\texorpdfstring{Theory\+:}{Theory\+:}}\label{README.md_autotoc_md396}
A task is simply a function that runs when the operating system (Freee\+RTOS) sees fit. This task can have an infinite loop inside if you want to do some work periodically for the entirety of the program run. This, however, can create a problem -\/ no other task will ever run and also the Watch Dog will trigger and your program will restart. A nice behaving tasks know when it is useless to keep the processor for itself and give it away for other tasks to be used. This can be achieved in many ways, but the simplest is called {\ttfamily delay(}milliseconds)\`{}. During that delay, any other task may run and do its job. When the delay runs out the Operating System gives the processor the task which can continue. For other ways to yield the CPU in a task please see other examples in this folder. It is also worth mentioning that two or more tasks running the same function will run them with separate stacks, so if you want to run the same code (which could be differentiated by the argument) there is no need to have multiple copies of the same function.

\begin{DoxyItemize}
\item {\bfseries{px\+Task\+Code}} is the name of your function which will run as a task
\item {\bfseries{pc\+Name}} is a string of human-\/readable descriptions for your task
\item {\bfseries{us\+Stack\+Depth}} is the number of words (word = 4 B) available to the task. If you see an error similar to this "{}\+Debug exception reason\+: Stack canary watchpoint triggered (\+Task Blink)"{} you should increase it
\item {\bfseries{pv\+Parameters}} is a parameter that will be passed to the task function -\/ it must be explicitly converted to (void\texorpdfstring{$\ast$}{*}) and in your function explicitly converted back to the intended data type.
\item {\bfseries{ux\+Priority}} is a number from 0 to config\+MAX\+\_\+\+PRIORITIES which determines how the Free\+RTOS will allow the tasks to run. 0 is the lowest priority.
\item {\bfseries{px\+Created\+Task}} task handle is a pointer to the task which allows you to manipulate the task -\/ delete it, suspend and resume. If you don\textquotesingle{}t need to do anything special with your task, simply pass NULL for this parameter. You can read more about task control here\+: \href{https://www.freertos.org/a00112.html}{\texttt{ https\+://www.\+freertos.\+org/a00112.\+html}}

This example supports all So\+Cs.\hypertarget{README.md_autotoc_md398}{}\doxysubsubsubsection{\texorpdfstring{Hardware Connection}{Hardware Connection}}\label{README.md_autotoc_md398}
If your board does not have a built-\/in LED, please connect one to the pin specified by the {\ttfamily LED\+\_\+\+BUILTIN} in the code (you can also change the number and connect it to the pin you desire).

Optionally you can connect the analog element to the pin. such as a variable resistor, analog input such as an audio signal, or any signal generator. However, if the pin is left unconnected it will receive background noise and you will also see a change in the signal when the pin is touched by a finger. Please refer to the ESP-\/\+IDF ADC documentation for specific SoC for info on which pins are available\+: \href{https://docs.espressif.com/projects/esp-idf/en/v4.4/esp32/api-reference/peripherals/adc.html}{\texttt{ ESP32}}, \href{https://docs.espressif.com/projects/esp-idf/en/v4.4/esp32s2/api-reference/peripherals/adc.html}{\texttt{ ESP32-\/\+S2}}, \href{https://docs.espressif.com/projects/esp-idf/en/v4.4/esp32s3/api-reference/peripherals/adc.html}{\texttt{ ESP32-\/\+S3}}, \href{https://docs.espressif.com/projects/esp-idf/en/v4.4/esp32c3/api-reference/peripherals/adc.html}{\texttt{ ESP32-\/\+C3}}\hypertarget{README.md_autotoc_md399}{}\doxysubsubsubsubsection{\texorpdfstring{Using Arduino IDE}{Using Arduino IDE}}\label{README.md_autotoc_md399}
