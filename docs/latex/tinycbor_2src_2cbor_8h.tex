Allocates memory for the string pointed by {\itshape value} and copies it into this buffer. The pointer to the buffer is stored in {\itshape buffer} and the number of bytes copied is stored in {\itshape buflen} (those variables must not be NULL).

If the iterator {\itshape value} does not point to a byte string, the behaviour is undefined, so checking with \doxylink{group___cbor_parsing_ga89c669eb345c1f6fa0c017e6a96d8fee}{cbor\+\_\+value\+\_\+get\+\_\+type} or \doxylink{group___cbor_parsing_ga2b8db3ef5ad00e753d91b80e4858cc09}{cbor\+\_\+value\+\_\+is\+\_\+byte\+\_\+string} is recommended.

If {\ttfamily malloc} returns a NULL pointer, this function will return error condition Cbor\+Error\+Out\+Of\+Memory.

On success, {\ttfamily }\{\texorpdfstring{$\ast$}{*}buffer\} will contain a valid pointer that must be freed by calling {\ttfamily }\{free()\}. This is the case even for zero-\/length strings.

The {\itshape next} pointer, if not null, will be updated to point to the next item after this string. If {\itshape value} points to the last item, then {\itshape next} will be invalid.

This function may not run in constant time (it will run in O(n) time on the number of chunks). It requires constant memory (O(1)) in addition to the malloc\textquotesingle{}ed block.

Converts the current CBOR type pointed to by {\itshape value} to its textual representation and writes it to the {\itshape out} stream. If an error occurs, this function returns an error code similar to Cbor\+Parsing.

The textual representation can be controlled by the {\itshape flags} parameter (see Cbor\+Pretty\+Flags for more information).

If no error ocurred, this function advances {\itshape value} to the next element. Often, concatenating the text representation of multiple elements can be done by appending a comma to the output stream in between calls to this function.
