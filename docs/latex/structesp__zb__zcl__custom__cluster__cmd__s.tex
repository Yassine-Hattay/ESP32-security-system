\doxysubsection{Detailed Description}
The Zigbee ZCL custom cluster command struct. 

\begin{DoxyNote}{Note}
For string data type, the first byte should be the length of string. For array, array16, array32, and long string data types, the first 2 bytes should represent the number of elements in the array. The size of data is only required when the type is ESP\+\_\+\+ZB\+\_\+\+ZCL\+\_\+\+ATTR\+\_\+\+TYPE\+\_\+\+SET, ESP\+\_\+\+ZB\+\_\+\+ZCL\+\_\+\+ATTR\+\_\+\+TYPE\+\_\+\+BAG, or CUSTOM\+\_\+\+TYPE.
