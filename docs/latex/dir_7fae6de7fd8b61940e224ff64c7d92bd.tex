\doxysubsection{Detailed Description}
The sample app demonstrates the use of APIs from {\itshape esp\+\_\+secure\+\_\+cert\+\_\+mgr} to retrieve the contents of the {\itshape esp\+\_\+secure\+\_\+cert} partition. The example can also be used to verify the validity of the contents from the {\itshape esp\+\_\+secure\+\_\+cert} partition.\hypertarget{README.md_autotoc_md1287}{}\doxysubsection{\texorpdfstring{Requirements}{Requirements}}\label{README.md_autotoc_md1287}
