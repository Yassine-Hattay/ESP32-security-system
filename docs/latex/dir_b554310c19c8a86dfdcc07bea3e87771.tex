\doxysubsection{Detailed Description}
Shows how to use m\+DNS to advertise and query services and hosts\hypertarget{README.md_autotoc_md1402}{}\doxysubsection{\texorpdfstring{Example workflow}{Example workflow}}\label{README.md_autotoc_md1402}

\begin{DoxyItemize}
\item m\+DNS is initialized with host name and instance name defined through the project configuration and {\ttfamily \+\_\+http.\+\_\+tcp} service is added to be advertised
\item A delegated host {\ttfamily esp32-\/delegated.\+\_\+local} is added and another {\ttfamily \+\_\+http.\+\_\+tcp} service is added for this host.
\item Wi\+Fi STA is started and trying to connect to the access point defined through the project configuration
\item The system event handler is used to pass the network events to m\+DNS so the service is aware when the interface comes up or down
\item GPIO0 (BOOT Button) is initialized as pulled-\/up input that can be monitored for button press
\item Example task is started to check if the button is pressed so it can execute the m\+DNS queries defined
\end{DoxyItemize}\hypertarget{README.md_autotoc_md1403}{}\doxysubsubsection{\texorpdfstring{Configure the project}{Configure the project}}\label{README.md_autotoc_md1403}

\begin{DoxyItemize}
\item Open the project configuration menu ({\ttfamily idf.\+py menuconfig})
\item Configure Wi-\/\+Fi or Ethernet under "{}\+Example Connection Configuration"{} menu
\item Set {\ttfamily m\+DNS Hostname} as host name prefix for the device and its instance name in {\ttfamily m\+DNS Instance Name}
\item Disable {\ttfamily Resolve test services} to prevent the example from querying defined names/services on startup (cause warnings in example logs, as illustrated below)
\end{DoxyItemize}\hypertarget{README.md_autotoc_md1404}{}\doxysubsubsection{\texorpdfstring{Build and Flash}{Build and Flash}}\label{README.md_autotoc_md1404}
Build the project and flash it to the board, then run monitor tool to view serial output\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{idf.py\ -\/p\ PORT\ flash\ monitor}

\end{DoxyCode}



\begin{DoxyItemize}
\item Wait for Wi\+Fi to connect to your access point
\item You can now ping the device at {\ttfamily \mbox{[}board-\/hostname\mbox{]}.local}, where {\ttfamily \mbox{[}board-\/hostname\mbox{]}} is preconfigured hostname, {\ttfamily esp32-\/mdns} by default.
\item You can also browse for {\ttfamily \+\_\+http.\+\_\+tcp} on the same network to find the advertised service
\item Pressing the BOOT button will start querying the local network for the predefined in {\ttfamily check\+\_\+button} hosts and services
\item Note that for purpose of CI tests, configuration options of {\ttfamily MDNS\+\_\+\+RESOLVE\+\_\+\+TEST\+\_\+\+SERVICES} and {\ttfamily MDNS\+\_\+\+ADD\+\_\+\+MAC\+\_\+\+TO\+\_\+\+HOSTNAME} are available, but disabled by default. If enabled, then the hostname suffix of last 3 bytes from device MAC address is added, e.\+g. {\ttfamily esp32-\/mdns-\/80\+FFFF}, and a query for test service is issued.
\end{DoxyItemize}

(To exit the serial monitor, type {\ttfamily Ctrl-\/\mbox{]}}.)
