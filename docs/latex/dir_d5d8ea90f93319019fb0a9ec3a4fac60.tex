\doxysubsection{Detailed Description}
This library allows to work with ESP Rain\+Maker.

ESP Rain\+Maker is an end-\/to-\/end solution offered by Espressif to enable remote control and monitoring for ESP32-\/\+S2 and ESP32 based products without any configuration required in the Cloud. The primary components of this solution are\+:


\begin{DoxyItemize}
\item Claiming Service (to get the Cloud connectivity credentials)
\item Rain\+Maker library (i.\+e. this library, to develop the firmware)
\item Rain\+Maker Cloud (backend, offering remote connectivity)
\item Rain\+Maker Phone App/\+CLI (\doxylink{class_client}{Client} utilities for remote access)
\end{DoxyItemize}

The key features of ESP Rain\+Maker are\+:


\begin{DoxyEnumerate}
\item Ability to define own devices and parameters, of any type, in the firmware.
\item Zero configuration required on the Cloud.
\item Phone apps that dynamically render the UI as per the device information.
\end{DoxyEnumerate}
