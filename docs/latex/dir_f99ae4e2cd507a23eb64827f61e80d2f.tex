\doxysubsection{Detailed Description}
This test uses \href{http://lcamtuf.coredump.cx/afl/}{\texttt{ american fuzzy lop}} to mangle real mdns packets and look for exceptions caused by the parser.

A few actual packets are collected and exported as bins in the {\ttfamily in} folder, which is then passed as input to AFL when testing. The setup procedure for the test includes all possible services and scenarios that could be used with the given input packets.\+The output of the parser before fuzzing can be found in \href{input_packets.txt}{\texttt{ input\+\_\+packets.\+txt}}\hypertarget{README.md_autotoc_md1413}{}\doxysubsection{\texorpdfstring{Building and running the tests using AFL}{Building and running the tests using AFL}}\label{README.md_autotoc_md1413}
To build and run the tests using AFL(afl-\/clang-\/fast) instrumentation


\begin{DoxyCode}{0}
\DoxyCodeLine{cd\ \$IDF\_PATH/components/mdns/test\_afl\_host}
\DoxyCodeLine{make\ fuzz}

\end{DoxyCode}


(Please note you have to install AFL instrumentation first, check {\ttfamily Installing AFL} section)\hypertarget{README.md_autotoc_md1414}{}\doxysubsection{\texorpdfstring{Building the tests using GCC INSTR(off)}{Building the tests using GCC INSTR(off)}}\label{README.md_autotoc_md1414}
To build the tests without AFL instrumentations and instead of that use GCC compiler(\+In this case it will only check for compilation issues and will not run AFL tests).


\begin{DoxyCode}{0}
\DoxyCodeLine{cd\ \$IDF\_PATH/components/mdns/test\_afl\_host}
\DoxyCodeLine{make\ INSTR=off}

\end{DoxyCode}


Note, that this setup is useful if we want to reproduce issues reported by fuzzer tests executed in the CI, or to simulate how the packet parser treats the input packets on the host machine.\hypertarget{README.md_autotoc_md1415}{}\doxysubsection{\texorpdfstring{Installing AFL}{Installing AFL}}\label{README.md_autotoc_md1415}
To run the test yourself, you need to download the \href{http://lcamtuf.coredump.cx/afl/releases/afl-latest.tgz}{\texttt{ latest afl archive}} and extract it to a folder on your computer.

The rest of the document will refer to that folder as {\ttfamily PATH\+\_\+\+TO\+\_\+\+AFL}.\hypertarget{README.md_autotoc_md1416}{}\doxysubsubsection{\texorpdfstring{Preparation}{Preparation}}\label{README.md_autotoc_md1416}

\begin{DoxyItemize}

Please note that if specified package version can\textquotesingle{}t be installed(due to system is the latest), you can download, build and install it manually.\hypertarget{README.md_autotoc_md1417}{}\doxysubsubsection{\texorpdfstring{Compile AFL}{Compile AFL}}\label{README.md_autotoc_md1417}
Compiling AFL is as easy as running make\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{cd\ [PATH\_TO\_AFL]}
\DoxyCodeLine{make}
\DoxyCodeLine{cd\ llvm\_mode/}
\DoxyCodeLine{make}

\end{DoxyCode}


After successful compilation, you can export the following variables to your shell (you can also add them to your profile if you want to use AFL in other projects).


\begin{DoxyCode}{0}
\DoxyCodeLine{export\ AFL\_PATH=[PATH\_TO\_AFL]}
\DoxyCodeLine{export\ PATH="{}\$AFL\_PATH:\$PATH"{}}

\end{DoxyCode}


Please note LLVM must be \texorpdfstring{$<$}{<}=4.\+0.\+0, otherwise afl does not compile, as there are some limitations with building AFL on Mac\+OS/\+Linux with the latest LLVM. Also, Windows build on cygwin is not fully supported.\hypertarget{README.md_autotoc_md1418}{}\doxysubsection{\texorpdfstring{Additional info}{Additional info}}\label{README.md_autotoc_md1418}
Apple has a crash reporting service that could interfere with AFLs normal operation. To turn that off, run the following command\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{launchctl\ unload\ -\/w\ /System/Library/LaunchAgents/com.apple.ReportCrash.plist}
\DoxyCodeLine{sudo\ launchctl\ unload\ -\/w\ /System/Library/LaunchDaemons/com.apple.ReportCrash.Root.plist}

\end{DoxyCode}


Ubuntu has a similar service. To turn that off, run as root\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{echo\ core\ >/proc/sys/kernel/core\_pattern}

\end{DoxyCode}
