Sodium is a new, easy-\/to-\/use software library for encryption, decryption, signatures, password hashing and more.

It is a portable, cross-\/compilable, installable, packageable fork of \href{http://nacl.cr.yp.to/}{\texttt{ Na\+Cl}}, with a compatible API, and an extended API to improve usability even further.

Its goal is to provide all of the core operations needed to build higher-\/level cryptographic tools.

Sodium supports a variety of compilers and operating systems, including Windows (with MingW or Visual Studio, x86 and x64), i\+OS, Android, as well as Javascript and Webassembly.\hypertarget{md__c_1_2_users_2hatta_2_desktop_2presonal-projects_2security-camera_2esp-idf-vs-ext_2_e_s_p-32-383308e1f082e809b4984ca2c0d6a5b3_autotoc_md1321}{}\doxysubsection{\texorpdfstring{Documentation}{Documentation}}\label{md__c_1_2_users_2hatta_2_desktop_2presonal-projects_2security-camera_2esp-idf-vs-ext_2_e_s_p-32-383308e1f082e809b4984ca2c0d6a5b3_autotoc_md1321}
