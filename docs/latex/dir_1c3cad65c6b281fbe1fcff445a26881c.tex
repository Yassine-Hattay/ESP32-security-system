\doxysubsection{Detailed Description}
A simple Serial compatible library using ESP32 classical Bluetooth Serial Port Profile (SPP)

Note\+: Since version 3.\+0.\+0 this library does not support legacy pairing (using fixed PIN consisting of 4 digits).\hypertarget{README.md_autotoc_md21}{}\doxysubsubsection{\texorpdfstring{How to use it?}{How to use it?}}\label{README.md_autotoc_md21}
There are 3 basic use cases\+: phone, other ESP32 or any MCU with a Bluetooth serial module\hypertarget{README.md_autotoc_md22}{}\doxysubsubsubsection{\texorpdfstring{Phone}{Phone}}\label{README.md_autotoc_md22}

\begin{DoxyItemize}
\item Download one of the Bluetooth terminal apps to your smartphone
\begin{DoxyItemize}
\item For \href{https://play.google.com/store/apps/details?id=de.kai_morich.serial_bluetooth_terminal}{\texttt{ Android}}
\item For \href{https://itunes.apple.com/us/app/hm10-bluetooth-serial-lite/id1030454675}{\texttt{ i\+OS}}
\end{DoxyItemize}
\item Flash an example sketch to your ESP32
\item Scan and pair the device to your smartphone
\item Open the Bluetooth terminal app and connect
\item Enjoy

There are two easy options and one difficult.

The easy options can be used as usual. These offer pairing with and without Secure Simple Pairing (SSP).

The difficult option offers legacy pairing (using fixed PIN) however this must be compiled with Arduino as an IDF component with disabled sdkconfig option {\ttfamily CONFIG\+\_\+\+BT\+\_\+\+SSP\+\_\+\+ENABLED}.\hypertarget{README.md_autotoc_md26}{}\doxysubsubsubsection{\texorpdfstring{Without SSP}{Without SSP}}\label{README.md_autotoc_md26}

This option is demonstrated in the example {\ttfamily Serial\+To\+Serial\+BT\+\_\+\+SSP}\`{}\mbox{]}(\href{https://github.com/espressif/arduino-esp32/blob/master/libraries/BluetoothSerial/examples/SerialToSerialBT_SSP/SerialToSerialBT_SSP.ino}{\texttt{ https\+://github.\+com/espressif/arduino-\/esp32/blob/master/libraries/\+Bluetooth\+Serial/examples/\+Serial\+To\+Serial\+BT\+\_\+\+SSP/\+Serial\+To\+Serial\+BT\+\_\+\+SSP.\+ino}})

The Secure Simple Pairing is enabled by calling method {\ttfamily enable\+SSP} which has two variants -\/ one is backward compatible without parameter {\ttfamily enable\+SSP()} and second with parameters {\ttfamily enable\+SSP(bool input\+Capability, bool output\+Capability)}. Similarly, the SSP can be disabled by calling {\ttfamily disable\+SSP()}.

Both options must be called before {\ttfamily begin()} or if it is called after {\ttfamily begin()} the driver needs to be restarted (call {\ttfamily end()} followed by {\ttfamily begin()}) in order to take in effect enabling or disabling the SSP.\hypertarget{README.md_autotoc_md28}{}\doxysubsubsubsection{\texorpdfstring{The parameters define the method of authentication\+:}{The parameters define the method of authentication\+:}}\label{README.md_autotoc_md28}

To use Legacy pairing you will have to use \href{https://espressif-docs.readthedocs-hosted.com/projects/arduino-esp32/en/latest/esp-idf_component.html}{\texttt{ Arduino as an IDF component}} and disable option {\ttfamily CONFIG\+\_\+\+BT\+\_\+\+SSP\+\_\+\+ENABLED}. Please refer to the documentation on how to setup Arduino as an IDF component and when you are done, run {\ttfamily idf.\+py menuconfig} navigate to {\ttfamily Component Config -\/\texorpdfstring{$>$}{>} Bluetooth -\/\texorpdfstring{$>$}{>} Bluedroid -\/\texorpdfstring{$>$}{>} \mbox{[} \mbox{]} Secure Simple Pairing} and disable it. While in the menuconfig you will also need to change the partition scheme {\ttfamily Partition Table -\/\texorpdfstring{$>$}{>} Partition Table -\/\texorpdfstring{$>$}{>} (X) Single Factory app (large), no OTA}. After these changes save \& quit menuconfig and you are ready to go\+: {\ttfamily idf.\+py monitor flash}. Please note that to use the PIN in smartphones and computers you need to use characters {\ttfamily Serial\+BT.\+set\+Pin("{}1234"{}, 4);} not a number {\ttfamily Serial\+BT.\+set\+Pin(1234, 4);} . Numbers CAN be used if the other side uses them too, but phones and computers use characters.
