Generic AT command to be send with pass and fail phrases.

Generic command that passes on supplied pass_phrase, and fails on fail_phrase.

Parameters
tCommandable object (anything that can accept commands)
commandCommand to be sent do the commandable object
pass_phraseString to be present in the reply to pass this command
fail_phraseString to be present in the reply to fail this command
timeout_msTimeout in ms
tAny "Command-able" class that implements "command()" method
commandCommand to issue
pass_phrasePattern to find in replies to complete the command successfully
fail_phraseIf this pattern found the command fails immediately
timeout_msCommand timeout in ms
Returns
Generic command return type (OK, FAIL, TIMEOUT)
