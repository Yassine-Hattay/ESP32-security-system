357/*
358 * Specific hash functions.
359 *
360 * Rules for contexts:
361 * -- No interior pointer.
362 * -- No pointer to external dynamically allocated resources.
363 * -- First field is called 'vtable' and is a pointer to a
364 * const-qualified br_hash_class instance (pointer is set by init()).
365 * -- SHA-224 and SHA-256 contexts are identical.
366 * -- SHA-384 and SHA-512 contexts are identical.
367 *
368 * Thus, contexts can be moved and cloned to capture the hash function
369 * current state; and there is no need for any explicit "release" function.
370 */
